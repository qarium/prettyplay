# Breaking Change Escalation Report

## Change

Remove the execution-context channel from generated step code (hotfix-step-context; plan.md in this directory): the `step_inputs` runtime global, the prompt rules that teach and enforce reading it, the manifest guarantee that grants it, and the tests that pin it. Generated and cached steps become self-contained — every value embedded as the literal rendered into the step.

## Why breaking

- `run_step_code(code, page)`: code reading `step_inputs` runs green today, raises `NameError` after the change.
- Legacy cache entries containing context reads (generated by the current prompt for every step whose values arrive through call `vars`) fail replay loudly; outside strict mode they self-heal through the existing regeneration loop under the new prompt, strict replays need the documented purge-after-upgrade.
- Engine CODEMANIFEST guarantee at :147 (the context global grant) is removed and replaced by the self-containment contract.
- Three existing tests pin the removed behavior and are rewritten.

## Why the change is nevertheless required

The owner's defect report: `step_inputs["vars"]["url"]` in generated step code is absolutely unacceptable — steps must use rendered values and know nothing about the context. The construct is prescribed by the current generation/steering prompts and enforced by the compliance gate for steps with inputs; it cannot be removed without changing the behavior of code that uses it. The affected behavior IS the defect.

## Rejected non-breaking alternative

Prompt-only fix (remove the teaching, flip the gate rule, keep the runtime global): leaves the context reachable, the manifest still grants it, legacy HISTORY records can still teach the pattern to regeneration, and the plain-sentence/template same-address replay hazard (silent `.get()` fallback, loud `KeyError`) remains reachable. Does not satisfy "steps know nothing about the context".

## Requested decision

Owner approval to proceed with the breaking change as planned (full removal), or selection of the non-breaking alternative.
